# Glossary (first-use explanations)

Plain-language first-use wording for recurring terms. These are definitions for the reader, not legal evidence: legal effects, dates and list membership still need a source in the ledger each issue. Explain at first visible use, e.g. "the US Bureau of Industry and Security (BIS)"; a later glossary entry does not count. The Chinese name helps you match terms in Chinese-language sources.

| Term | First-use wording (English) | Chinese name |
|---|---|---|
| BIS | the US Commerce Department's Bureau of Industry and Security (BIS), which administers export controls | 美国商务部工业与安全局 |
| EAR | the US Export Administration Regulations (EAR), which set which items need a licence to export | 美国《出口管理条例》 |
| Entity List | the Entity List, a BIS list whose members generally need a licence to receive items subject to the EAR | 实体清单 |
| Affiliates Rule | the Affiliates Rule, which extends export restrictions to companies 50% or more owned by listed entities | 关联方规则（50% 规则） |
| Military end user (MEU) | the military end-user (MEU) rule, which restricts exports to military users in specified countries | 军事最终用户 |
| 1260H list | the US Defense Department's list of "Chinese military companies", updated yearly under Section 1260H of the National Defense Authorization Act (the 1260H list) | 1260H 名单（中国军事企业名单） |
| NS-CMIC | the US Treasury's Non-SDN Chinese Military-Industrial Complex Companies List (NS-CMIC); US persons may not trade the listed companies' public securities | 中国军工复合体企业名单 |
| OFAC | the US Treasury's Office of Foreign Assets Control (OFAC), which administers sanctions | 美国财政部外国资产控制办公室 |
| SDN | the Specially Designated Nationals list (SDN), OFAC's main sanctions list | 特别指定国民名单 |
| COINS Act | a provision of the FY2026 National Defense Authorization Act (the COINS Act) requiring periodic review of whether 1260H companies belong on the NS-CMIC list | — |
| MOFCOM | China's Ministry of Commerce (MOFCOM), which administers China's export controls and trade remedies | 商务部 |
| MIIT | China's Ministry of Industry and Information Technology (MIIT) | 工业和信息化部（工信部） |
| CAC | the Cyberspace Administration of China (CAC), China's internet and data regulator | 国家互联网信息办公室（网信办） |
| NDRC | China's National Development and Reform Commission (NDRC), the state planning agency | 国家发展和改革委员会 |
| Busan Agreement | the Busan Agreement, the trade truce reached after the Trump–Xi meeting in Busan, South Korea, in October 2025 | 釜山协议 |
| FCC | the US Federal Communications Commission (FCC), which certifies electronic equipment for the US market | 美国联邦通信委员会 |
| APEC | the Asia-Pacific Economic Cooperation forum (APEC) | 亚太经济合作组织 |
| KYC | know-your-customer (KYC) checks on a client's identity and background | 了解你的客户 |
| GPU | graphics processing unit (GPU), the chip type most used for AI computing | 图形处理器 |
| H200 | Nvidia's H200, a data-centre AI accelerator | — |
| RTX Pro series | Nvidia's RTX Pro series, professional graphics processors positioned below its data-centre AI accelerators | RTX Pro 系列 |
| HBM | high-bandwidth memory (HBM), stacked memory that feeds data to AI chips at high speed | 高带宽内存 |
| CoWoS | TSMC's CoWoS advanced packaging, which places processors and high-bandwidth memory in one package | 台积电先进封装 |
| Silicon interposer | the silicon interposer, the layer in advanced packaging that connects processor and memory | 硅中介层 |
| KV Cache | the key-value cache (KV cache), stored intermediate results that avoid recomputation during model inference | 键值缓存 |
| MoE / active parameters | mixture-of-experts (MoE) models, which use only some sub-networks per step; "active parameters" are those used for each output | 混合专家模型 / 激活参数 |
| NPU | neural processing unit (NPU) | 神经网络处理器 |
| SSD | solid-state drive (SSD) | 固态硬盘 |
| TSMC | Taiwan Semiconductor Manufacturing Co (TSMC), the largest contract chipmaker and a leader in advanced packaging | 台积电 |
| GF | GlobalFoundries (GF), a US contract chipmaker | 格芯 |
| SMIC | Semiconductor Manufacturing International Corp (SMIC), China's largest contract chipmaker | 中芯国际 |
| CXMT | ChangXin Memory Technologies (CXMT), China's leading DRAM maker | 长鑫存储 |
| YMTC | Yangtze Memory Technologies (YMTC), China's leading NAND flash maker | 长江存储 |
