# Glossary (first-use explanations)

Plain-language first-use wording for recurring terms. These are definitions for the reader, not legal evidence: legal effects, dates and list membership still need a source in the ledger each issue. Explain at first visible use; a later glossary entry does not count.

| Term | First-use wording (Chinese) |
|---|---|
| BIS | 美国商务部工业与安全局（BIS），负责出口管制 |
| EAR | 美国《出口管理条例》（EAR），规定哪些物项出口需要许可 |
| Entity List | 实体清单：BIS 名单，向列名方出口受 EAR 管辖的物项通常需要许可 |
| Affiliates Rule | 关联方规则：把出口限制扩展到受限实体合计持股 50% 以上的企业 |
| Military end user (MEU) | 军事最终用户：EAR 中限制向特定国家军事用户出口物项的规则 |
| 1260H list | 美国国防部"中国军事企业"名单（依据《国防授权法》第 1260H 条每年更新，简称 1260H 名单） |
| NS-CMIC | 美国财政部的"中国军工复合体企业"名单（NS-CMIC），美国人士不得买卖名单企业的公开交易证券 |
| OFAC | 美国财政部外国资产控制办公室（OFAC），负责制裁 |
| SDN | 特别指定国民名单（SDN），OFAC 的主要制裁名单 |
| COINS Act | 美国《2026 财年国防授权法》中的一项条款（COINS Act），要求定期评估 1260H 名单企业是否应列入 NS-CMIC 名单 |
| MOFCOM | 中国商务部 |
| MIIT | 中国工业和信息化部（工信部） |
| CAC | 国家互联网信息办公室（网信办） |
| Busan Agreement | 釜山协议：2025 年 10 月特朗普与习近平在韩国釜山会晤后达成的经贸休战安排 |
| FCC | 美国联邦通信委员会（FCC），负责电子设备进入美国市场的认证 |
| APEC | 亚太经济合作组织（APEC） |
| KYC | 了解你的客户（KYC），即客户身份与背景尽调 |
| GPU | 图形处理器（GPU），常用于 AI 计算 |
| H200 | Nvidia 面向数据中心的 AI 加速器（H200） |
| RTX Pro series | Nvidia 专业图形处理器（RTX Pro 系列），定位低于数据中心 AI 加速器 |
| HBM | 高带宽内存（HBM），为 AI 芯片提供高速数据传输 |
| CoWoS | 台积电的先进封装技术（CoWoS），把处理芯片与高带宽内存封装在一起 |
| Silicon interposer | 硅中介层：先进封装中连接处理芯片与内存的部件 |
| KV Cache | 键值缓存（KV Cache）：模型推理时保存已计算信息，避免重复计算 |
| MoE / active parameters | 混合专家模型：每次只调用部分子网络；激活参数指单次生成实际调用的参数量 |
| NPU | 神经网络处理器（NPU） |
| SSD | 固态硬盘（SSD） |
| TSMC | 台积电（TSMC），晶圆代工与先进封装企业 |
| GF | 格芯（GlobalFoundries，简称 GF），美国晶圆代工企业 |
